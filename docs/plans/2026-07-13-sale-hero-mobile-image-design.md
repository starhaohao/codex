# Sale Hero Mobile Image

## Approved direction

Use a clean portrait version of the existing sale campaign artwork. Do not regenerate the model or alter the campaign styling.

## Implementation

- Keep the current desktop hero image unchanged.
- Add a separate `Mobile hero image` picker to the Sale Hero section.
- Serve the mobile image only below 750 px.
- Fall back to the desktop image when no mobile image is selected.
- Use the existing 1536 x 1920 portrait campaign asset for mobile.
